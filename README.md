# ru-code-reader — говорилка

Бесплатная офлайн-озвучка выделенного текста для Windows и Android (Termux).
Сделана под чтение вывода Claude Code: русский и английский вперемешку, код, логи, числа, даты, единицы, символы.

Выделил → нажал → слушаешь. Пауза, продолжение (даже после перезапуска), переходы по фразам, перемотка, скорость.

Собрано в октябре 2026. Код и README написаны вместе с Claude.

---

## Что в архиве

| Файл | Где нужен | Что делает |
|---|---|---|
| `prep.py` | везде | Готовит текст к чтению: числа и даты словами с падежами, английские слова русскими буквами, символы, единицы, паузы. Здесь же словари `CUSTOM` (как читать английские слова) и `STRESS` (ручные ударения для Vosk). |
| `xtts_server.py` | везде | Фоновый сервер. Режет текст на фразы, синтезирует каждую в файл, играет через mpv, помнит место. Платформу определяет сам. |
| `say.py` | везде | Клиент: шлёт серверу команды, сам запускает сервер, если тот не работает. |
| `say.ahk` | Windows | Горячие клавиши (AutoHotkey v2). |
| `setup_phone.sh` | Android | Ставит всё в Termux и настраивает уведомление с кнопками. |
| `clipwatch.sh` | Android | Раз в полсекунды сохраняет буфер обмена в `~/clip.txt`. |

---

## Управление

**Windows** (клавиши работают и в русской раскладке):

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+S | прочитать выделенное (буфер обмена) с начала |
| Ctrl+Alt+X | пауза / продолжить (и после выгрузки сервера) |
| Ctrl+Alt+, и Ctrl+Alt+. | к прошлой / следующей фразе |
| Ctrl+Alt+[ и Ctrl+Alt+] | на 5 секунд назад / вперёд |
| Ctrl+Alt+; и Ctrl+Alt+' | на 10% медленнее / быстрее (сбрасывается при новом тексте и перезапуске) |

Если ничего не играет, перемотка только сдвигает место, а Ctrl+Alt+X начинает оттуда.

**Android** — уведомление-плеер:
⏮ прошлая фраза · ▶ прочитать буфер с начала · ⏸ новый текст — читать, тот же — пауза/продолжить · ⏭ следующая фраза.

## Установка на Windows

Все файлы кладутся в одну папку (дальше — «папка озвучки», например `%USERPROFILE%\ru-code-reader`): скрипты ищут друг друга рядом с собой, там же появятся лог, кэш фраз и `say_last.txt`.

1. **Python 3.12** с python.org (галочка «Add to PATH»).
2. **Библиотеки:**
   ```
   python -m pip install vosk-tts onnxruntime num2words pymorphy3 cmudict
   ```
   Именно `onnxruntime`, не `onnxruntime-gpu`: Vosk работает на процессоре, видеокарта не нужна.
3. **Модель Vosk** `vosk-model-tts-ru-0.9-multi` — скачать zip с https://alphacephei.com/vosk/models и распаковать так, чтобы получилось
   `%USERPROFILE%\.cache\vosk\vosk-model-tts-ru-0.9-multi\model.onnx`.
4. **mpv** — https://mpv.io; сервер найдёт его в PATH или в `C:\Program Files\MPV Player\` / `C:\Program Files\mpv\` (иначе впиши путь в `MPV` в сервере).
5. **Piper** (запасной голос, если Vosk не загрузится) — необязательно:
   `piper.exe` из релизов https://github.com/rhasspy/piper — в подпапку `piper\` папки озвучки,
   голос `ru_RU-ruslan-medium.onnx` + `.onnx.json` (https://huggingface.co/rhasspy/piper-voices, ru/ru_RU/ruslan/medium) — в подпапку `voices\`.
6. **Файлы** `prep.py`, `xtts_server.py`, `say.py`, `say.ahk` — в папку озвучки.
7. **AutoHotkey v2** — поставить и запустить `say.ahk` (чтобы работало после перезагрузки — положить ярлык в `shell:startup`).

Нажми Ctrl+Alt+S на любом тексте: сервер стартует сам, Vosk загрузится секунд за 5.

Лог: `xtts_server.log` в папке озвучки. Что ушло в синтез после подготовки: `say_last.txt`.
Перезапуск сервера: `Stop-Process -Name pythonw -Force`, потом Ctrl+Alt+S. `prep.py` перезапуска не требует — сервер перечитывает его сам.

## Установка на Android (Termux)

Голос — Piper (Руслан) внутри proot-Ubuntu, потому что Vosk телефону не по силам.

1. **Termux** и **Termux:API** — из F-Droid (версии из Google Play устаревшие).
2. **Пакеты:**
   ```
   pkg install python mpv termux-api proot-distro
   proot-distro install ubuntu
   ```
3. **Piper в Ubuntu:**
   ```
   proot-distro login ubuntu
   cd /root
   # piper_linux_aarch64.tar.gz из релизов https://github.com/rhasspy/piper
   tar xzf piper_linux_aarch64.tar.gz          # получится /root/piper/piper
   mkdir -p voices                              # сюда ru_RU-ruslan-medium.onnx и .onnx.json
   exit
   ```
   Пути заданы в `xtts_server.py`: `ANDROID_PIPER`, `ANDROID_VOICE`.
4. **Файлы и настройка:** положи все файлы архива в одну папку на телефоне и запусти
   ```
   termux-setup-storage      # если Termux ещё не видит память телефона
   bash путь/к/папке/setup_phone.sh
   ```
   Он скопирует файлы в `~/tts`, поставит библиотеки, впишет в `~/.bashrc` запуск clipwatch и уведомления (старый `.bashrc` — в `.bashrc.bak`).

**Как пользоваться:** копируй текст **внутри Termux**, подожди секунду, потом тяни шторку и жми кнопку.

Лог: `~/tts/xtts_server.log`. Перезапуск: `pkill -f tts/xtts_server.py`.

## Настройки (верх `xtts_server.py`)

- `VOSK_SPEAKER` — 3 мужской, 2 женский. `VOSK_RATE` — скорость Vosk.
- `IDLE_MIN` — через сколько минут простоя выгружать Vosk (освобождает ~1,6 ГБ).
- `SENT_PAUSE`, `LINE_PAUSE`, `PARA_PAUSE` — паузы между предложениями, строками, абзацами.
- `LONG_CHARS` — длиннее этого предложение режется по запятым.
- `SEEK_SEC`, `SPEED_STEP` — шаг перемотки и скорости.
- `USE_RUACCENT` — ударения через RuAccent (см. ниже), по умолчанию выключено.
- `PIPER_SPEED` — скорость Руслана (меньше — быстрее).

Как читать конкретное английское слово — словарь `CUSTOM` в `prep.py` (`'window': 'виндоу'`).
Ручное ударение для Vosk — словарь `STRESS` в `prep.py` (`'деплоить': 'депл+оить'`).
Флаг `TRANSLIT = False` в `prep.py` оставляет английские слова латиницей — только для голоса, который сам читает английский.

## Грабли, на которые уже наступили

- **Vosk грузился 9 минут.** Виноват не диск и не видеокарта: onnxruntime минутами планирует переиспользование памяти на модели из 17 тысяч узлов. Лечится `enable_mem_reuse = False` и `enable_mem_pattern = False` в настройках сессии — загрузка 2 секунды. Уже сделано в сервере.
- **В фоне всё было в 4–8 раз медленнее.** Windows душит фоновые процессы без окна (EcoQoS). Сервер отключает это через `SetProcessInformation`, но вызовы ctypes на 64-битной Windows молча не срабатывают без явно заданных `argtypes`/`restype`. Уже сделано.
- **Видеокарта не нужна.** На GPU Vosk грузился дольше и съедал 3 ГБ видеопамяти, а на процессоре синтезирует в 4–5 раз быстрее речи.
- **RuAccent** (`pip install ruaccent`) ставит ударения и «ё» точнее словаря Vosk, но ест ещё ~1 ГБ памяти и замедляет синтез — поэтому выключен. Если включать: ему нужен обычный `onnxruntime` (не `-gpu`, они конфликтуют), при первом запуске качает модели с Hugging Face — не перезапускать сервер, пока в логе не появится «RuAccent загружен». Сервер сам подставляет `token_type_ids`, которые новые transformers перестали передавать.
- **Android не отдаёт буфер обмена приложениям в фоне.** Кнопка в шторке — уже фон. Поэтому `clipwatch.sh` сохраняет буфер, пока Termux на экране, и копировать надо внутри Termux. Разрешение `adb shell cmd appops set --uid com.termux.api READ_CLIPBOARD allow` на Xiaomi не помогло. Если понадобится читать из других приложений — путь через «Поделиться»: приложение HTTP Shortcuts (F-Droid), которое шлёт текст серверу; для этого серверу нужно научиться принимать HTTP — не сделано.
- **mosh ломает прокрутку в Claude Code** (свайп превращается в мусорные символы), даже 1.4.0 на обеих сторонах. Для серверов — ssh с автопереподключением и tmux.
- **Нумерация списков** при копировании из чата Claude в буфер не попадает — браузер рисует её сам. Это не баг `prep.py`.
